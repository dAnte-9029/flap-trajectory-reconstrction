## 2. 物理定义、时间与权重

所有优化保留原生异步时刻。IMU 使用 `timestamp_sample`，GNSS 使用原生接收/发布时刻减显式假设延迟；没有将所有传感器插值到共同频率。200 Hz CSV 仅为连续轨迹的分析导出网格。

| 来源 | 比较的物理量 | 本次处理和限制 |
|---|---|---|
| GNSS PVT | `p + R l`；`v + R(ω×l)` | 真实接收机位置/速度；LLA→固定局部 NED，速度亦变换到同一局部基底；零杆臂、110 ms 延迟均为未标定假设 |
| sensor_gyro | `ω^B + b_g` | 设备 offset、板级旋转后 FRD；段内常偏置估计，零中心启发式先验；不导入 EKF bias |
| sensor_accel | `Rᵀ(a^N−g^N)+b_a` | 校准后比力，`g^N=[0,0,9.80665]`；不与导航系加速度直接相减 |
| vehicle_attitude | SO(3) 测地角差异 | 初始化及非独立参考；不作为额外优化因子 |
| vehicle_local_position | 复位/参考坐标检查 | 不作为第二套独立 GNSS 因子；未计算所谓独立位置真值误差 |
| encoder_count / wing_phase | 连续机械相位、速度 | 固定全量拟合 32 Hz 平滑尺度；绝对机械零点未独立标定 |
| α^B | 连续轨迹角加速度 | 无直接真值；仅导数/积分和敏感性检查，未报告“真实角加速度 RMSE” |

参考点定义为主 IMU 位置，在刚性安装假设下 IMU 杆臂为零。它不等于已知质心。若换参考点，传感器比力必须增加 `α×l_IMU + ω×(ω×l_IMU)` 等刚体项；当前没有假装已标定非零 IMU/质心杆臂，也没有把未建模结构形变解释为刚体真值。

复用已有设备标定与固件源文件核验，元数据保存 calibration、frame、参数和源码 SHA。主设置：knot=50 ms，WNOJ 平移/旋转 PSD=10000/1000，IMU 有效 sigma=1.5 m/s²、0.05 rad/s，bias prior sigma=0.5 m/s²、0.02 rad/s。GNSS 为接收机对角协方差代理加固定 floor（位置 0.1/0.1/0.2 m、速度 0.15 m/s），保留位置和速度，使用 Stage02.6 验证的 G0 六维联合 Huber(3)。这些权重不是标定噪声，也不是后验置信区间。

## 5. 运动学与离散积分

六条主结果（A/B/完整航次 × 两方案）均通过独立非 knot 对齐有限差分、全部内部 GP knot/连续相位 spline 边界和数值积分。阈值沿用 5e-3 SI 数值一致性检查，未为了本次结果放宽。

完整航次在 h=1e-6 s 的最坏差分误差：直接 `p_dot−v / v_dot−a / R_dot−ω / ω_dot−α` 为 **6.41e-8 / 1.78e-6 / 4.55e-9 / 1.79e-6**；相位为 **9.14e-8 / 2.47e-6 / 9.29e-9 / 1.17e-6**。边界两侧差随 epsilon 缩小而收敛，epsilon=1e-11 s 时两方案所有 GP/相位边界的 a/α 差异 <9.6e-8（各自 SI 单位），并非强制零差。

在 23 个固定 off-grid 起点，以 2 ms →0.5 ms→0.125 ms 独立中点积分检查 20/50/100/200 ms 窗口。完整航次最细步长、四个窗口中的最大闭合误差：位置 <3.5e-8 m，速度 <6.4e-6 m/s，姿态 <4.7e-8 rad，角速度 <2.3e-6 rad/s。

但是，左端点近似 `v(t+Δt)≈v(t)+a(t)Δt` 的最大差异，直接方案在 20/50/100/200 ms 为 **0.177/0.630/1.770/3.894 m/s**，相位为 **0.188/0.807/1.879/5.228 m/s**。对应左端点角速度差，直接为 **0.286/1.348/4.456/7.058 rad/s**，相位为 **0.460/2.463/5.245/10.368 rad/s**。这是曲线在该离散近似下的误差，不是传感器真值误差；本次未改变轨迹去迎合该积分器，也未声称验证了外部动力学项目的具体积分实现。

这些对照是确定性情景差异，不是置信区间，也不能直接当作完整航次的稳定性范围。本次未单独改变未知 IMU→COM 杆臂：参考点已定义在 IMU；对其他参考点的运动/刚性假设仍未验证。未估计可靠后验协方差、未分离结构振动/采样混叠的因果来源。
