## 2. 编码器、Hall 与频率的计算链

从原始日志对应的固件提交直接读取五个文件，分别保存 A/B 快照、路径和哈希：`AS5600.cpp`、`AS5600Math.hpp`、`WingPhase.cpp`、`WingPhaseMath.cpp/.hpp`。A 固件为 `a644ca7868f07004e45658d4ae9a7a8c880c6bb5`，B 为 `d0dd2354fdeadfbe505211a17b54d728309fedff`。这是固定源码核对，不是修改或重新运行固件。

1. AS5600 原始位置为一转 4096 计数。相邻位置差按 ±2048 处理电机轴整圈回绕，累加为 `total_count`。相邻角度差除以实际 `dt` 得到转速；`dt` 无效或大于 0.5 秒时另行处理。记录时间来自读数后的 `hrt_absolute_time()`，不能把时间戳分辨率直接认成采样准确度。
2. 转速经 `rpm_estimate = 0.8 rpm_estimate + 0.2 rpm_raw` 低通；`flap_frequency=abs(rpm_estimate)/(60 FLAP_RATIO)`，低于 0.2 Hz 时置零。两个目标片段不在该低频分支内。
3. `WingPhase` 消费编码器和 Hall。`WingPhaseMath` 在相邻编码器样本间线性插值 Hall 时间对应计数；时间不在样本范围内则返回无效。符合锁定/重触发条件后更新 `_zero_count`。
4. Hall-relative 相位来自 `(total_count-zero_count)×2π/counts_per_cycle`，wrapped 相位再取模。其 `phase_unwrapped_rad` 仍会在 Hall 零点更新时复位；`phase_valid` 主要表示软件已有可用零点，不是独立 Hall 质量认证。

**频率计算不依赖 Hall 相位。** 实际按累计计数增量、原生时间间隔和 α=0.2 回放记录频率：A/B RMSE 为 `3.48e−7 / 3.59e−7 Hz`，最大差 `1.09e−6 / 1.14e−6 Hz`。回放以首条记录滤波值初始化，因此不验证更早的滤波历史；浮点误差量级的剩余差支持片段内的计算链一致性。这一同源关系没有被当作第二组独立观测加权。

## 4. Hall 的处理：固定一个参考，不把台阶加入运动

相位观测定义为

\[
\phi_{enc}(t_i)=\phi_0+\frac{2\pi}{4096r}(C_i-C_0),
\]

其中 φ₀ 取片段首个有效 Hall-indexed 相位作为**固定坐标约定**。后续 Hall 软件复位不进入运动拟合，全部保留为诊断。用户允许将 Hall 用作零点诊断，本次没有在缺少独立脉冲时刻的情况下伪造高精度 Hall 因子。

复用并重新定位全部 157 次复位：139 次修正小于 1°，18 次约 11.4°–12.2°。大修正在 A 为六组正负配对、持续约 0.25–1.63 秒；B 为三组负正配对、持续约 0.24–0.26 秒。这些持续的参考偏移没有被摊成真实加减速。事件起止样本、幅值、与连续相位的差保存在 `hall_diagnostics.csv`；配对持续时间、进入/离开修正与未知原因保存在 `hall_offset_episodes.csv`，并与旧诊断证据对应。`phase_quality.json` 单独记录零点、时钟与各阶导数的可信边界。

**不能确定原因。** 固件说明偏移在哪个计算环节加入，却不说明 Hall 触发、脉冲选择、时间匹配或机械索引为何变化。软件复位出现的样本间隔不是精确 Hall 脉冲时刻。约 12° 是观察到的参考分歧，不是已标定的绝对零点误差上界。

如果更换 φ₀，整条相位只改变常数，φ̇/φ̈ 不变，已做数值验证。跨航次使用统一周期模型之前，仍需确认机械索引零点的可比性；固定 sin/cos 回归可以吸收常量偏移，并不因此证明绝对相位已经正确。

## 5. 一条连续相位及事前选参规则

复用 SciPy 1.11.4 `make_smoothing_spline` 的自然三次平滑样条，求解

\[
\min_{\phi}\sum_i|\phi_{enc}(t_i)-\phi(t_i)|^2
+\lambda\int |\phi''(t)|^2dt.
\]

模型至少 C²；φ、φ̇、φ̈ 都由这条样条及同一个恢复的线性趋势计算。线性去趋势仅改善数值条件，其二阶导数为零，不改变目标函数。没有重新实现样条/GP 求解器。[SciPy 对应版本官方方法说明](https://docs.scipy.org/doc/scipy-1.11.4/reference/generated/scipy.interpolate.make_smoothing_spline.html)

事前固定三个尺度 `8 / 16 / 32 Hz`，用 `λ=1/[median(dt)(2π尺度)^4]` 映射为约 `1.5665e−5 / 9.7904e−7 / 6.1190e−8 s³`。这些尺度以 100 Hz 观测、3–5 Hz 基频及 9–15 Hz 第三谐波为依据，分别覆盖较强、居中、较弱平滑；**它们是连续均匀近似下的半幅尺度，不是已标定的实际离散截止频率。**

第一轮仅查看固定稀疏留出：原生行号 `%5==2`，边界两点保留。按 A/B 等权平均的留出计数 RMSE 选共同参数，2% 内平手取更强平滑。结果选择 **32 Hz 尺度，λ≈6.119e−8 s³**；选择发生在查看连续块或 IMU 周期结果之前。它是预定三档中最弱的一档，不能称为全局最优，也没有据此继续扩大搜索。

随后验证四个相对上下文起点 4/8/12/16 秒、各 60 ms 的连续计数留出区间。最后用全部编码器计数重拟合选定参数，导出每段一条最终曲线。留出拟合文件与全量重拟合文件分开保存，不能把最终拟合误差当留出误差。

自然样条端点的二阶导数为零，是边界条件而非测量事实。因此全域可查询，但原 16 秒内区间单独标记 `interior_derivative_support`，外围约 2 秒只作上下文。不外推、不跨缺口拼接。对每个三次段的一阶导数二次多项式检查端点和内部极值，全部严格正向；不是只在画图网格上检查单调性。

## 7. 导数、积分与异常台阶

实际验证包含普通内部时段、普通复位、最大归零修正、编码器速度变化最大处，部分普通事件位于上下文，输出中明确保留支持域标记。

- 独立中心差分步长 `1e−3 → 1e−4 → 1e−5 s` 下，一阶导数最大误差降低到 `3.92e−7 rad/s`，二阶到 `0.00652 rad/s²`。接近样条 knot 时三阶导数可不连续，不强求跨 knot 的二阶中心差分仍有统一二阶收敛率。
- knot 左右距离 `1e−6 / 1e−8 / 1e−10 s` 的 φ/φ̇/φ̈ 差随距离缩小；最小距离时最大约 `6.3e−9 rad / 4.6e−8 rad/s / 3.1e−6 rad/s²`，支持 C² 连续。没有要求 jerk 连续。
- 独立自适应数值积分（按 knot 分割）恢复相位或速度增量，最大闭合误差 `3.34e−12`，对应各自单位；没有仅调用样条解析原函数证明自己。
- 原始固定网格中点积分保留了接近 10 ms 网格时的微小误差平台，初次“所有时段严格单调改善”的断言失败。原因是分段线性加速度的折点距离积分网格只有微秒级，若细分仍未分辨这一位置，误差可能暂时不变。原数据和失败检查代码均保留，没有改模型或隐去失败。
- 随后先记录 `integration_followup_plan.json`，将同一时段起止错开 `+3.17 / −1.43 ms`，固定 `23/91/367/1471` 个中点子区间。最大相位积分误差从 `7.59e−4` 降到 `1.88e−7 rad`，速度积分误差从 `0.1646` 降到 `6.9e−5 rad/s`；各时段最细均优于最粗。收敛受分段位置影响，不宣称统一高阶收敛。

所选全量拟合的内区间频率范围 A/B 约 `2.59–4.94 / 2.78–4.72 Hz`。旧 Hall 相位差分曾出现约 `0.2 / 7.8 Hz` 的极值，新模型不接收那些台阶，因此不再产生该归零成因的导数尖峰。**这是编码器运动与参考零点分离的结果，不是用强低通压掉所有峰值。**

## 8. 频率变化保留与二阶导数可信度

用新轨迹的**区间相位增量**换算平均频率，与同一区间编码器频率比较，避免将点瞬时频率与区间平均混为一谈：A/B RMSE `0.0213 / 0.0205 Hz`，中心化标准差比 `0.996 / 0.993`。同时保存瞬时频率供查询，绘图明确两者的区别。

原生非均匀时间 Lomb–Scargle 频谱与固定一至三阶周期回归显示：所选样条保留编码器一/二/三阶幅值约 A `99.98% / 99.63% / 97.53%`、B `99.97% / 99.61% / 97.05%`。强平滑 8 Hz 尺度则显著削弱二/三阶。这里证明的是**编码器记录的周期转速变化得到保留**，不是证明全部变化都没有磁角度误差或传动影响。记录低通频率的幅值和相位与瞬时速度不同，未作为独立约束。

可信度应分开判断：

| 量 | 当前证据与可信边界 |
|---|---|
| 相对连续 φ | 计数直接约束，稀疏与短块留出支持，固定坐标内较可靠；绝对机械零点仍未知 |
| φ̇ / 频率 | 符合计数增量、低通频率链及周期动态，内区间可作为条件性研究输入；时间准确度和编码器角度误差未标定 |
| φ̈ | 数学定义和闭合已验证；真实值仍属低可信度候选，对时间扰动和正则强度明显敏感 |
| 外围上下文导数 | 自然边界条件影响较大，不与核心 16 秒同等使用 |

敏感性只作场景对照，不是后验方差或置信区间：

- 改用相邻的 16 Hz 尺度，内区间相位/频率差 RMS 仅约 `0.002 rad / 0.023 Hz`，但 φ̈ 差约 A/B `32.96 / 32.54 rad/s²`；所选 φ̈ 自身 RMS 约 `82.81 / 84.06 rad/s²`。
- 固定种子、各 8 次 ±0.5 计数均匀扰动，最大场景 RMS 差约 `4.2e−5 rad / 0.00069 Hz / 1.25 rad/s²`。
- 固定种子、各 8 次 **假设** ±50 μs 时间戳扰动，最大场景差约 `0.00055 rad / 0.0086 Hz / 15.9 rad/s²`。50 μs 不是已经测出的时间误差界；记录的时间间隔抖动也不等同于实际采样时间误差。

因此 φ̈ 可用于带敏感性分析的后续公式验证，不能直接作为真实机械加速度标签。三档曲线的逐时刻包络已保存，但没有将其标为置信区间。

## 9. 有解析真值的合成检查

合成相位包含约 4 Hz 基础转速、缓慢变化以及 4/12 Hz 相位调制；采用近 100 Hz 不均匀时刻、整数计数量化，另向 Hall 参考注入 ±12° 台阶。编码器不含台阶，拟合从未读取人工 Hall 台阶，因而只验证隔离机制，不冒充物理归因。

所选 32 Hz 尺度在内区间的相位/速度/加速度真值 RMSE 为 `5.82e−5 rad / 0.00529 rad/s / 1.242 rad/s²`。较强平滑的加速度误差更大，原始结果全部保存。验证常数零点变换不改变导数；无效输入、缺口、计数复位、重复时间和域外查询被拒绝。

这些是已运行合成结果，不能推广为 A/B 实测相位加速度误差。最终五组聚焦检查通过，覆盖数据身份与计算链、合成及拒绝规则、实际数值一致性、序列化/单调性/质量标记和 16 个 H3 拟合的留出隔离。

例如分散整周期的 accel-z RMSE A `4.462 → 4.248`、B `4.214 → 4.173 m/s²`；gyro-y A `0.2580 → 0.2344`、B `0.2154 → 0.2115 rad/s`。以同一旧相位基作评估坐标，A gyro-y 基频相位误差中位绝对值由 `0.165 → 0.086 rad`，第三谐波幅值比由 `0.897 → 0.990`；B gyro-y 第三谐波相位误差则由 `0.161 → 0.181 rad`。负面结果保留。

这表明去除软件归零台阶没有整体破坏跨翼拍对齐，且 A 有一定收益；它不证明已解决 GPTR 惯性过拟合，也不把相干 IMU 分量认证为整机刚体运动。
