## 2. 实现与事前固定方案

### 2.1 复用部分

GPTR 固定提交 `2c0285a4f3141b131cc7b3aa77b3c6d979c0a2c2`，继续复用 `GPMixer`、`GaussianProcess`、`GPMotionPriorTwoKnotsFactor`。Stage 01 的查询、SO(3) ambient Jacobian 和 build-local PSI 修正全部保留，没有修改上游 Fork，也没有实现新 GP 求解器。

Baseline 直接使用原 `GPIMUFactor` 和 Stage 02 `PVTFactor`；新模型使用最小 Ceres 组合因子。只对新增的组合运动和传感器映射使用 Ceres Jet 自动求导，然后链乘上游 GP endpoint Jacobian。重力、偏置、协方差白化、Huber、时间和有效性定义相同。

构建使用已有 `flap-recon` 的 Ceres 2.2、Eigen、Sophus、GCC 15；Python 使用已有 SciPy 1.11.4。没有安装新依赖。上游工作区保持干净。

### 2.2 单一组合轨迹

对整段固定的位移系数和旋转切向量系数分别采用 H=1 或 H=3 的 sin/cos 基，单位分别为 **NED 米**、**右乘 FRD 切向量弧度**。没有把加速度计傅里叶系数当作位移初值。

\[
p=p_s+p_{osc}(\phi),\quad R=R_sQ,\quad Q=\operatorname{Exp}(\eta(\phi)).
\]

\[
v=v_s+p'_{osc}(\phi)\dot\phi,\quad
 a=a_s+p''_{osc}(\phi)\dot\phi^2+p'_{osc}(\phi)\ddot\phi.
\]

令 \(\omega_q=J_r(\eta)\dot\eta\)，\(\alpha_q=\dot J_r\dot\eta+J_r\ddot\eta\)，则

\[
\omega=Q^{-1}\omega_s+\omega_q,\qquad
\alpha=Q^{-1}\alpha_s-\omega_q\times(Q^{-1}\omega_s)+\alpha_q.
\]

所有量来自同一组合轨迹。周期系数不随传感器采样任意变化；本次固定系数，因此没有遗漏非零系数时间导数。相位及两阶导数来自同一 C² 编码器曲线的精确三次多项式，不强制重采样、不外推、不拟合相位延迟。Hall 后续归零台阶不进入运动。

IMU 预测为 \(f=R^{-1}(a-g_{NED})+b_a\)、\(\omega+b_g\)，其中 \(g_{NED}=(0,0,9.80665)\)。代码沿用原因子的负重力向量加法。GNSS 为 \(p+R\ell\)、\(v+R(\omega\times\ell)\)，查询时刻为接收时间减固定假设延迟。加速度计和陀螺分别在自身原生时刻查询。EKF 只提供初始姿态，不作为独立观测因子。

### 2.3 冻结方案与公平性

`configs/stage02_3B_joint.json` 在新增求解前写入并复制为 `frozen_config.json`：

- 统一 **50 ms knot**；主方案 WNOJ 强度乘数 q=0.1，即平动/旋转 Qc=10⁴/10³。它来自既有先验敏感性背景，未依据本次结果选择。q 越大，运动先验越弱。
- H0 原 GPTR、H1、H3；周期系数零均值 Gaussian prior：位置每轴每个 sin/cos 的标准差 0.05/h² m，旋转 0.05/h rad。WNOJ 作用于慢变状态，属于模型分配假设。
- 观测 σ：accel 1.5 m/s²、gyro 0.05 rad/s；恒定偏置先验 σ：0.5 m/s²、0.02 rad/s；Huber 半径 3；GNSS 原协方差和掩码不变。
- GNSS 延迟主假设 110 ms，天线杆臂主假设零，相位延迟零。都不是本次测量标定值。
- A 4 秒 H0/H3；A/B 16 秒各 H0/H1/H3；A-H3 额外五项：相位16 Hz、q=1、GNSS延迟0、杆臂(0.1,0.05,0.03)m、固定小扰动系数初值。**总计13次，不搜索其它组合。**
- 整翼拍掩码沿用 Stage 02.2；留出周期内 accel 和 gyro 都不进入因子，gyro 初始化也排除。两模型使用同样 GNSS 训练观测和 EKF 姿态初始化，所有目标观测、时间和掩码已逐点核对一致。

**公平不等于独立。** 编码器相位允许作为外生信息，GNSS 留出规则不变；EKF 初值可能间接含留出 IMU，同一设备相邻翼拍也相关。因此只说明条件性预测能力。Stage 02 的逐样本留出 12～13 m/s² 不参与本次方法排名。

## 3. 实际数学与工程验证

1. 合成慢变非周期平动、非共轴旋转、非恒定相位速度，以及一/三阶周期运动。独立中心差分 h=10⁻⁶ s 时，v/a/ω/α 各项最大绝对误差均小于 **2.59×10⁻⁷**（各自SI单位，不作跨量纲加总）；非零杆臂 PVT 位置导数与速度差小于 **1.69×10⁻⁹ m/s**。
2. 合成独立中点积分从 2 ms 缩至 0.125 ms，H3 的速度误差从 7.28×10⁻⁴ 降至 2.84×10⁻⁶ m/s，角速度误差从 2.26×10⁻³ 降至 8.81×10⁻⁶ rad/s。数值收敛与差分互相支持。
3. 新系数/偏置 Jacobian 最坏归一化误差 **1.72×10⁻⁸**；GP endpoint 链最坏 **2.83×10⁻⁷**。包含零周期幅值、小转角、非零偏置/重力、非零杆臂和非对角协方差。周期系数为零时，与原 IMU/PVT 因子残差差 **1.58×10⁻¹⁶**。
4. SciPy→C++ 精确相位分段导出，φ/φ̇/φ̈ 最大误差分别不超过 **1.14×10⁻¹³ / 9.10×10⁻¹³ / 1.34×10⁻¹⁰**。另用 Stage 02.2 的独立 Python 组合实现核对实际求解结果，最大差小于 **2.42×10⁻¹¹**。
5. 序列化 knot/系数后重新查询，已保存时刻最大差小于 **4.49×10⁻¹¹**；另查询非网格时刻，全部有限。每段完整检查 1600 个相位多项式边界。
6. 真实全部相位求解的抽样 Jacobian monitor：endpoint 最坏 **8.73×10⁻⁶**，新增系数/偏置最坏 **6.04×10⁻⁹**，分别满足预设 5×10⁻³/10⁻⁵ 监测界限。未发现需要修正上游小角度实现的实质证据。

上述是**实际运行**，对应 `synthetic.csv`、`query_validation.json`、`phase_boundary_limits.csv` 和各求解诊断。没有用数学闭合宣称物理准确。也没有运行全状态合成可辨识性证明；Jacobian 正确不意味着运动分配可辨识。

向量 RMSE 定义为 \(\sqrt{\operatorname{mean}\|y_{pred}-y_{obs}\|^2}\)，不是三轴 RMSE 的平均。拟合指标只统计目标窗口参与拟合的原生点，求解同时使用固定上下文。

|---|---:|---:|---:|---:|
| A H0 | 4.236 | 12.708 | 0.209 | 1.063 |
| A H1 | 4.234 | 11.896 | 0.200 | 0.656 |
| A H3 | 4.231 | 11.278 | 0.193 | 0.515 |
| B H0 | 4.496 | 14.923 | 0.215 | 0.987 |
| B H1 | 4.499 | 14.593 | 0.203 | 0.695 |

逐周期结果：A/B 加速度有 **11/12、9/13** 个翼拍改善，仍分别有 1/4 个退化；陀螺 **12/12、13/13** 改善。前/后半段及描述性的高/低频组均为平均改善，但 B 前半段加速度收益较弱。分组仅用于稳定性描述，不是另一次独立检验，也没有据此调参。

## 5. 运动学一致性与离散接口

### 6.2 周期项与慢变项耦合

50ms baseline 有 **7224** 个局部优化标量，H1为7236，H3为7260。相对于旧20ms轨迹总维数较少，但**公平50ms baseline与H3相比，新增了36个变量，没有证明有效自由度更少**。本次没有计算可辨识秩或有效自由度，不能将固定周期系数个数当作证据替代。

A/B H3 的位移系数整体范数为0.01218/0.01586m，旋转系数范数0.03050/0.02489rad。慢变分量仍承担 accel-z 基频幅值6.514/4.423m/s²；总预测幅值12.415/13.126，周期效应6.705/8.775。由于相位和旋转耦合，幅值不能直接相加。gyro-y 的慢变基频仅约0.035/0.032rad/s，旋转分配比平动清楚，但这仍不是刚体归因证明。

**确定性的系数交换诊断**：把周期系数乘0.8或1.2，并反向组合慢变 knot 的 p/v/a/R/ω/α，使总 knot 状态保持不变；不重新优化。A/B总曲线的 p RMS 变化约3.52/4.05微米，a RMS仅约0.052/0.061m/s²，ω RMS约0.00138/0.00168rad/s。如此大的系数变化只引起很小的观测层变化，说明周期分配具有明显冗余，主要受先验和表示约定选择。`exchange.csv` 的先验成本是目标内的成本，不能与含上下文的总成本直接相减。

固定初值重启复现了相近最优值：A系数差约2.33×10⁻⁶m/1.01×10⁻⁶rad，a RMS差0.00262m/s²。这支持局部数值稳定，**不推翻上面的物理/参数耦合，也不证明全局唯一**。

- **先验不足仍是已验证的风险。** q=1 时加速度留出翻倍，而拟合目标成本更低；不同先验的目标成本本来也不能直接排名。相位结构没有阻止非周期/慢变 GP 的过度灵活性。
- **φ̈不是本次大误差的唯一解释。** 16Hz替代改变 φ、φ̇、φ̈，重新优化后留出几乎不变，却使平动周期系数差范数达0.00867m，约为主系数范数的71%。这展示“预测类似、分配不同”。固定主解中仅来自 φ̈ 链式项的加速度/角加速度贡献，抽样 RMS A/B约0.73/1.03m/s²、2.23/1.74rad/s²；不能忽略，也不能删去该项后仍宣称运动学一致。这是贡献量诊断，不是其误差估计。
- **110ms不是已估计真延迟。** 改成0会显著改变路径、姿态、加速度和偏置。A-H3加速度偏置从约(−0.980,0.247,−0.470)变为(0.586,−0.409,0.023)m/s²。不同观测指标变化方向不一致，没有条件凭最小某项残差“标定”延迟。
- **杆臂只是一个假设情景。** 0.1/0.05/0.03m导致的位置差有参考点/杆臂几何成分；不能全部解释为轨迹估计误差。真实安装刚性、IMU至机体/质心及天线外参仍未测量验证。
- **偏置是联合拟合的 nuisance 参数，不是独立校准。** H0到H3的gyro偏置明显改变，说明基线可能用偏置吸收未建模周期或姿态变化；现有数据不支持据此宣布某一组偏置为真实值。

可信度分开表述：GNSS支持宏观位置/速度，但速度时延与周期响应仍不确定；IMU支持可重复角速度和部分低阶谐波，姿态依赖初始化/偏置/时间；线加速度留出和先验敏感性仍不足；角加速度虽可一致求导，受未观测频带、相位二阶导数及局部振动影响，仍为候选量。

## 8. 原因、下一步条件与停止结论

**问题 → 证据 → 原因 → 建议措施：**

1. **加速度仍过拟合。** 拟合约4.2～4.5而整周期留出11.3～14.1；q=1退化到23.9。已验证GP灵活性/先验强度是重要因素，尚不能将残差完全分成噪声、振动或表示误差。下一步应先定义慢变与周期分量的可解释分配约束，例如明确的相位投影/正交约定或带宽先验，并预先保留非周期机动；不能只继续减小q或加谐波。
2. **周期旋转有收益，但平动分配不稳定。** 陀螺全部留出翼拍改善、谐波恢复；平动系数交换和相位敏感性显示冗余。可以继续复用本阶段组合、查询和因子，优先检验一个有明确分配约定的受限版本。固定NED位移系数能否充分描述随姿态/工况变化的周期运动，目前只是可能的表示限制，没有在本阶段验证替代模型。
3. **传感器周期扰动与刚体运动尚不可分。** 同相位相干性与低残差都不能证明刚性。需要同步的额外刚性位置/姿态观测、不同安装位置的同步IMU、安装/天线几何和时间标定，或有依据的结构响应模型。下一阶段若探索扰动项，应与周期运动形成受限、可辨识的替代假设；不同时放开相同基函数的两个自由分量。
4. **运动学一致不等于标签可靠。** 组合数学、数值积分和查询接口已验证；真实加速度仍有明显留出缺口。20ms离散接口需明确瞬时量、有效增量与旋转更新的区别，不能靠扭曲周期运动适配左端积分。

**最终判定为 CONDITIONAL，针对继续研究，不针对正式标签验收。** 当前有可用的相位感知六自由度联合优化原型和可复现实验轨迹；角速度泛化收益跨A/B一致，加速度仅部分改善。继续之前，应冻结新的慢变/周期分配假设与完整翼拍验收条件，验证加速度是否稳定接近观测回归基线、非周期机动是否保留，以及对时间/外参/相位尺度是否更稳健。A/B仍只是开发航段，任何以后独立验证都需要另行预注册，不能把本次选择后的A/B重称独立测试。

本次没有自行进入上述下一步，没有新增自由周期传感器扰动，没有正式或实验性训练标签导出。所有当前 p/v/a/R/ω/α 仅是带限制说明的研究用轨迹。
