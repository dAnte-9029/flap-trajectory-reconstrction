## 问题：是不是只有正常的 360° 回绕？

不是。先对 `phase_rad` 作常规 unwrap，再与同一时刻的编码器增量比较：

\[
\epsilon_i = (\phi_i^{unwrap}-\phi_{i-1}^{unwrap})
-\frac{2\pi(C_i-C_{i-1})}{4096\,FLAP\_RATIO}.
\]

这里 `FLAP_RATIO=7.9090909958`。编码器累计相位只在片段起点与记录相位对齐，**没有作平滑或额外拟合，也不是独立物理真值**。两者同源，正适合用来定位归零逻辑引入的额外修正。

复位由 Hall-relative `phase_unwrapped_rad` 的负向大跳变定位；该字段不是永远累计的全局相位。A/B 共 157 次复位。非复位间隔中，两种相位增量最大差仅为 A `8.15e−7`、B `6.90e−7` rad，符合保存精度范围。与 Stage 02.2 先前数值的末位差来自本次直接解析已保存十进制 CSV，未更改源文件。

## 证据：不是连续小抖动，而有两类明显不同的修正

| 统计量 | A | B |
|---|---:|---:|
| 复位次数 | 78 | 79 |
| 修正绝对值中位数 | 0.270° | 0.137° |
| 小修正次数 / 最大值 | 66 / 0.900° | 73 / 0.571° |
| 大修正次数 / 绝对值范围 | 12 / 11.722°–12.195° | 6 / 11.379°–12.107° |
| 去回绕相位差分的频率范围 | 0.202–7.787 Hz | 0.199–7.290 Hz |
| 编码器增量对应的频率范围 | 2.590–5.025 Hz | 2.770–4.702 Hz |
| 修正引起的一阶差分最大差 | 3.388 Hz | 3.359 Hz |
| 修正引起的二阶差分最大差 | 2128.90 rad/s² | 2110.45 rad/s² |

5° 只用于将两个明显分离的簇作描述性统计，不是选定的数据剔除阈值；实际上两簇之间约 0.9°–11.4° 没有样本。上述二阶数值是**相位二阶差分**，不是机体角加速度，更不是已经测准的真实机构角加速度。差分采用实际时间间隔，一阶值放在区间中点，二阶值采用相邻一阶中点的时间间隔。

在大修正序列中，A 六组均为先正后负，B 三组均为先负后正；每组修正和绝对值不超过约 0.386°。A 台阶持续约 0.25–1.63 秒，B 约 0.24–0.26 秒。**因此不只是单个样本坏点：部分相位零点偏移持续一个或多个翼拍，然后恢复。** 初始绝对相位未知，不能仅凭差值平台判定哪一级一定正确。

图中普通事件选取绝对修正接近中位数且上下文充分的复位；极端事件取全片段最大绝对修正，没有按 IMU 拟合效果挑选。局部图阴影表示首次观察到软件修正的两个日志样本之间，不是独立测得的 Hall 脉冲时刻。

## 原因：已经能定位到归零修正，但尚未定位触发源

固定固件的 `WingPhase.cpp` 显示：相位依据编码器累计计数及 `_zero_count` 计算，Hall 到来后，通过相邻编码器样本插值 Hall 时刻的计数，更新 `_zero_count`。在这两段中，额外修正只出现在对应归零间隔，非归零时沿用编码器增量。这解释了台阶为何能在直接求导中产生尖峰。

**尚不能证明**约 12° 的切换由哪一具体环节造成。Hall 触发边沿、脉冲选择、时间匹配、机构索引变化等均需进一步证据；两份日志缺少 `hall_event`，不能直接验证脉冲时间、漏脉冲或毛刺。观察到成对恢复，不足以单独诊断某个驱动错误，也不能证明编码器没有自身误差。

记录的 `flap_frequency` 是编码器转速的低通结果；它与相位不是独立测量。局部图也显示，即使不受大归零修正影响，编码器速度仍有周期内变化，低通频率并不逐点等同于相位差分。不能用常数频率或任意强平滑抹去这些变化后就称为正确相位。

## 建议措施：处理相位零点与连续演化，而不是只删导数尖峰

1. **正常回绕：**在有效连续区间内 unwrap，解决 360° 表示问题；不跨无效点或缺口。该步骤不能去掉这里的额外 ±12° 修正。
2. **额外归零：**优先研究“编码器增量约束连续演化＋带不确定性的周期参考/归零偏移”的表示。应能描述整段零点偏移，避免把它强迫解释成机构的瞬间加减速。纯累计编码器可作诊断基线，但不能直接取代所有 Hall 约束，否则可能积累传动比或计数误差。
3. **求导：**在区分零点变化后，才拟合统一的 C² 连续相位，由同一个函数得到相位、一阶和二阶导数。仅用逐点插值、PCHIP 或分别平滑 phase/frequency，不能自动满足这里对二阶连续性及导数一致性的要求。拟合强度需依据编码器增量、周期参考误差与动态保留验证，不能以 IMU 残差最小为选择依据。
4. **后续验证：**先在已知真实相位＋归零台阶的合成信号上验证不会制造导数尖峰，再在这些固定事件上核对周期时长、计数增量及周期内速度变化的保留；若要确认根因，应补查同版本 Hall 事件生成/时间链，并在可用记录中取得独立 Hall 时间或机械相位参照。

当前图足以否定“只做 unwrap 然后直接求导”，也提示“只去掉跳变一个点再补值”不充分；**尚不足以决定平滑强度、认定某一相位平台是真值或保证周期加速度准确。** 本次停留在可视化诊断，没有替换 Stage 02.2 的相位，也未进入 Stage 03。
